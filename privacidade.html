Política de Privacidade

Última atualização: 19/11/2026

O aplicativo "History alt" é uma ferramenta de uso pessoal do dono do canal History alt. Ele serve apenas para publicar os vídeos do próprio canal no YouTube e no TikTok.

YouTube API Services

Este aplicativo usa os YouTube API Services. Ao usar o aplicativo, você concorda com os Termos de Serviço do YouTube. A Política de Privacidade do Google está em: https://policies.google.com/privacy.

Quais dados são acessados

Quando o dono do canal autoriza o aplicativo, o Google envia um token OAuth. Usamos esse token somente para enviar vídeos ao próprio canal do dono (método videos.insert, permissão youtube.upload).

Não vemos vídeos, não lemos estatísticas (analytics) e não acessamos dados de outros usuários.

Onde ficam os dados

O token fica salvo somente no computador do dono do canal. Ele nunca é compartilhado, vendido ou enviado a terceiros. Não guardamos senhas.

Eliminação de dados e revogação de acesso

Para retirar o acesso do aplicativo à conta Google, abra https://security.google.com/settings/security/permissions e remova o "History alt". Depois, apague o arquivo local do token.

Os dados são apagados em até 7 dias após o pedido. Pedidos: david.wo.anjos@gmail.com

TikTok

Quando o dono autoriza o aplicativo, o TikTok envia um código de acesso. Usamos esse código só para enviar os vídeos escolhidos pelo dono. Não coletamos dados de outras pessoas e não compartilhamos dados com terceiros. O código fica salvo apenas no computador do dono. O acesso pode ser retirado a qualquer momento nas configurações de segurança da conta do TikTok.

Privacy Policy

Last updated: 19/11/2026

"History alt" is a personal tool of the owner of the History alt channel. It is used only to publish the channel's own videos to YouTube and TikTok.

YouTube API Services

This app uses YouTube API Services. By using the app, you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy is at: https://policies.google.com/privacy.

Data accessed

When the channel owner authorizes the app, Google issues an OAuth token. We use it only to upload videos to the owner's own channel (videos.insert, youtube.upload scope).

We do not view videos, read analytics, or access any other user's data.

Storage

The token is stored only on the owner's computer. It is never shared, sold or sent to third parties. We do not store passwords.

Data deletion and revocation

To revoke the app's access to the Google account, open https://security.google.com/settings/security/permissions and remove "History alt". Then delete the local token file.

Data is deleted within 7 days of a request. Requests: david.wo.anjos@gmail.com

TikTok

When the owner authorizes the app, TikTok sends an access code. We use it only to upload videos chosen by the owner. We collect no data from other people and share nothing with third parties. The code is stored only on the owner's computer. Access can be revoked at any time in the TikTok account security settings.
