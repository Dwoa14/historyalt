Política de Privacidade

Última atualização: 18/11/2026

O aplicativo "History alt" é uma ferramenta de uso pessoal do dono do canal History alt. Ele serve apenas para publicar os vídeos do próprio canal no TikTok.

Quais dados usamos

Quando o dono do canal autoriza o aplicativo, o TikTok envia um código de acesso. Usamos esse código só para enviar os vídeos escolhidos pelo dono.

O que não fazemos

Não coletamos dados de outras pessoas. Não vendemos nem compartilhamos dados com terceiros. Não guardamos senhas.

Onde ficam os dados

O código de acesso fica salvo apenas no computador do dono do canal.

Como apagar

O dono pode retirar o acesso a qualquer momento nas configurações de segurança da conta do TikTok.
